# UpdateProjectRequest

All fields optional; only supplied fields are updated.
`visibility`/`chatSharing` are owner-only — an editor who is not
the owner gets `403` if they include either field. Flattened (not
`allOf: [CreateProjectRequest, ...]`) since `CreateProjectRequest`
itself is `additionalProperties: false` — composing two closed
schemas would reject `visibility`/`chatSharing` on every real update.
