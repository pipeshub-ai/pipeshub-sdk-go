# MessagePart

One entry in the ordered agent-activity transcript for a message turn.
Every field beyond `type` is optional and depends on the part kind, and
`sub_agent` nests this same shape recursively under `parts`.

Tool results here are always a bounded preview, never the full payload —
`artifactId` points at the complete result.
