# OAuthConfigRecord

An OAuth configuration as `GET /oauth/{connectorType}` lists it. An admin gets the stored
record in full, credentials included. Any other caller gets only the `OAuthConfig` fields.
The provider fields (`authorizeUrl`, `tokenUrl`, `redirectUri`, `scopes` and the optional ones
after them) are copied from the OAuth registry when the configuration is created, so a
configuration created under a type that is not in the registry has none of them.
